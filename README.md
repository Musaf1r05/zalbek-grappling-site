# Сайт Залбека Рустамова

Адаптивный лендинг на HTML, CSS и JavaScript без серверной части, формы заявок и онлайн-оплаты.

## Файлы

- `index.html` — тексты, расписание, цены, ссылки, фото и порядок блоков.
- `style.css` — внешний вид и мобильная адаптация; основные цвета заданы переменными в начале файла.
- `script.js` — меню, анимации и карта.
- `images/` — локальные фото и логотип; фото из галереи зала добавлены с разрешения тренера.
- `videos/` — локальное MP4-видео для галереи сайта.
- `vendor/leaflet/` — локальная библиотека интерактивной карты Leaflet (BSD-2-Clause).

## Карта и видео

Карта находится внизу страницы, позволяет перемещать вид и менять масштаб. Это чёрно-белая карта OpenStreetMap без рекламных маркеров; тайлы загружаются с openstreetmap.de, атрибуция видна на карте. Кнопки отдельно открывают маршрут в Яндекс Картах и карточку зала в 2ГИС.

В галерее используется локальный MP4-файл из папки `videos/`. Видео загружается с сайта и воспроизводится стандартным плеером браузера.

## Связь

Telegram, ВКонтакте, Instagram и номер телефона открываются по нажатию. WhatsApp и MAX не добавлены. Форма заявок, онлайн-оплата, база и аналитика не подключены. Google Fonts и рекламные скрипты не используются.

## Открыть сайт

Открой `index.html` в браузере. Для карты и внешних ссылок понадобится интернет; локальное видео находится в проекте.

## Редактирование

Инструкция находится в [КАК_РЕДАКТИРОВАТЬ.md](КАК_РЕДАКТИРОВАТЬ.md). Можно присылать текст, фото и видео сюда — редактировать код самостоятельно необязательно.
